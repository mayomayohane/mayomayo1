# Windowsで「刺さった歌詞」アプリを動かす手順

Macがなくても、**Windowsのパソコン**と**iPhone**だけで開発を進められます。
この手順書では、専門用語が初めて出てきたときに **（かっこ）** で簡単に説明しています。

---

## 全体の流れ

```
[Windows PC]  コードを書く・開発サーバーを動かす
     │  同じWi-Fi
     ▼
[iPhone]  「Expo Go」アプリで、作っているアプリをその場で確認
     │  （あとで）
     ▼
[EAS Build（クラウド）]  本番用のアプリを作って App Store / TestFlight へ
```

- **Expo（エキスポ）**：React の書き方で iPhone/Android アプリを作れる仕組み（React Native）を、さらに簡単にしてくれる道具一式。
- **Expo Go**：iPhone に入れる無料アプリ。パソコンで書いたコードを、ビルド（＝アプリの形に組み立てる作業）なしで、すぐ iPhone 上で動かせます。

---

## ステップ0：必要なものを入れる（最初の1回だけ）

### 0-1. Node.js（ノード・ジェイエス）

JavaScript をパソコン上で動かすためのソフトです。Expo の道具はこれの上で動きます。

1. https://nodejs.org/ja を開く
2. **「LTS」**（＝長期サポート版。安定していておすすめ）と書かれた方をダウンロードしてインストール
3. インストール中の設定は、基本的に全部そのまま「Next」でOK

インストールできたか確認します。スタートメニューで **「PowerShell」**（＝文字でパソコンに命令を出す画面。「ターミナル」とも呼びます）を開いて、次を入力して Enter：

```powershell
node -v
npm -v
```

`v22.x.x` のような数字が出れば成功です。
（**npm** は Node.js と一緒に入る「部品（ライブラリ）をダウンロードする道具」です）

> 💡 PowerShell で「スクリプトの実行が無効」というエラーが出たら、次を1回だけ実行してください。
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

### 0-2. Git（ギット）

コードの変更履歴を管理する道具です。GitHub からコードを取ってくるのにも使います。

1. https://git-scm.com/download/win からダウンロードしてインストール（設定はそのままでOK）
2. PowerShell を一度閉じて開き直し、`git --version` で確認

### 0-3. VS Code（コードを書くエディタ）

https://code.visualstudio.com/ からインストール。
日本語化したい場合は、拡張機能から「Japanese Language Pack」を入れます。

### 0-4. iPhone に Expo Go を入れる

App Store で **「Expo Go」** を検索してインストールします。

## ステップ1：プロジェクトをパソコンに持ってくる

このリポジトリ（＝GitHub 上のプロジェクト置き場）には、すでに MVP の3機能を作ったコードが入っています。

PowerShell で、作業したい場所（例：ドキュメントフォルダ）に移動してから取ってきます：

```powershell
cd ~\Documents
git clone https://github.com/mayomayohane/mayomayo1.git
cd mayomayo1
git checkout claude/hopeful-turing-ed861w
cd lyrics-app
```

- `cd` ＝ フォルダを移動する命令
- `git clone` ＝ GitHub からプロジェクトを丸ごとコピーする命令
- `git checkout` ＝ 作業の「ブランチ」（＝本流から枝分かれした作業場所）を切り替える命令

> 💡 リポジトリが非公開（private）の場合、`git clone` のときに GitHub のログイン画面が出ます。ブラウザでログインすれば続きが進みます。

> 💡 このブランチの内容を本流（main）に取り込んだあとは、`git checkout` の行は不要です。

```powershell
npm install
```

`node_modules` というフォルダができ、アプリに必要な部品（Expo、画面遷移、通知など）がダウンロードされます。数分かかることがあります。

## ステップ3：開発サーバーを起動して iPhone で動かす

```powershell
npx expo start
```

- `npx` ＝ インストールした道具をその場で実行する命令

画面に大きな **QRコード** が表示されます。

1. iPhone とパソコンを **同じWi-Fi** につなぐ
2. iPhone の **標準カメラアプリ** で QR コードを読み取る
3. 「Expo Go で開く」をタップ

アプリが iPhone に表示されれば成功です 🎉

> ⚠️ 初回は Windows の「ファイアウォール」（＝外部からの通信を防ぐ壁）の確認画面が出ることがあります。**「プライベートネットワーク」にチェックを入れて「許可」** してください。

### つながらないとき

- Wi-Fi が別々（会社や学校のWi-Fiなど）だとつながらないことがあります。次の方法を試してください：
  ```powershell
  npx expo start --tunnel
  ```
  （**トンネル** ＝ インターネット経由でパソコンと iPhone をつなぐ方法。少し遅いですが、Wi-Fi が違っても動きます。初回は追加の部品のインストールを聞かれるので `y` で進めます）

### パソコンのブラウザで画面だけ確認したいとき

PowerShell で `npx expo start` を動かしているときに **`w` キー** を押すと、ブラウザで画面が開きます。
（通知機能はブラウザでは動きません。通知は iPhone で確認してください）

### 開発サーバーを止めるとき

PowerShell で **`Ctrl + C`** を押します。

## ステップ4：実際に使ってみる（動作確認）

### MVP① 歌詞を保存する
1. 下の **「保存」** タブを開く
2. Spotify や LINE MUSIC の歌詞画面で、刺さった一節を長押し → コピー
3. Expo Go に戻って「刺さった一節」に貼り付け、曲名・アーティスト名を入力
4. 「保存する」をタップ

### MVP② 一覧で見返す
- **「一覧」** タブに、保存した歌詞がカードで並びます
- 「ランダムに1つ」で、ランダムに1つ選んでいちばん上に表示
- カードを **長押し** すると削除できます

### MVP③ ランダム通知
1. **「通知」** タブで「毎日ランダムに届ける」をオンにする
2. 通知の許可を聞かれたら「許可」
3. 届く時刻を「＋／−」で調整（分は15分刻み）
4. 「テスト通知を送る（5秒後）」を押してホーム画面に戻ると、5秒後に通知が届きます

## ステップ5：コードを少し変えてみる（練習）

VS Code で `lyrics-app` フォルダを開いてみましょう（VS Code の「ファイル」→「フォルダーを開く」）。

例：色を変えてみる。`src/lib/theme.js` の `accent` を

```js
accent: '#B4533A',
```

から

```js
accent: '#3A6EB4',
```

に変えて保存（`Ctrl + S`）すると、iPhone の画面が **自動で更新** されます（**ホットリロード**＝保存するとすぐ画面に反映される機能）。

## フォルダの中身（どこに何があるか）

```
lyrics-app/
├── app.json              アプリ名やアイコンなどの設定
├── package.json          使っている部品の一覧
├── assets/               アイコン画像など
└── src/
    ├── app/              ★ ここにあるファイル1つ = 1画面（Expo Router の決まり）
    │   ├── _layout.js    画面下のタブ（一覧・保存・通知）の設定
    │   ├── index.js      MVP② 一覧画面
    │   ├── add.js        MVP① 保存画面
    │   └── settings.js   MVP③ 通知の設定画面
    └── lib/              画面ではない共通の処理
        ├── storage.js         端末にデータを保存・読み込み
        ├── LyricsContext.js   歌詞と設定を全画面で共有する仕組み
        ├── notifications.js   ランダム通知の予約
        └── theme.js           色やフォントの設定
```

- **Expo Router（エキスポ・ルーター）**：`src/app` に置いたファイルを、自動で画面として扱ってくれる仕組み。
- 保存したデータは **iPhone の中だけ** に保存され、外部のサーバーには送られません（歌詞の著作権の面でも安心な、個人利用の形です）。

### ランダム通知のしくみ（少し詳しく）

iPhone の **ローカル通知**（＝アプリ自身が予約する通知。サーバー不要）を使っています。
「毎日21時」の繰り返し通知だと毎回同じ文面になってしまうため、**これから30日分を、1日ずつ違う歌詞で予約** しています。
アプリを開くたびに予約し直すので、ときどき開けば通知が途切れることはありません。
（iOS では一度に予約できる通知が64件までなので、30日分にしています）

## 次のステップ（MVPのあと）

### A. Expo Go なしで、自分の iPhone に本物のアプリとして入れる

Expo Go は開発中の確認用です。ホーム画面に独立したアプリとして入れるには、**EAS Build**（＝Expo のクラウド上でアプリを組み立ててくれるサービス。Mac 不要）を使います。

```powershell
npm install -g eas-cli      # EAS の道具を入れる
eas login                   # Expo アカウントでログイン（無料で作れます）
eas build:configure         # 初回設定（eas.json が作られます）
eas build --platform ios    # クラウドで iPhone 用アプリを作る
eas submit --platform ios   # App Store Connect に送る → TestFlight で自分の iPhone に入れられる
```

- 途中で Apple ID でのログインを聞かれます。Apple Developer Program に加入済みなので、証明書（＝アプリの身分証明書）などは EAS が自動で作ってくれます。
- **TestFlight**：App Store に公開する前に、自分や知り合いの iPhone にアプリを配れる Apple 公式の仕組み。
- アプリの「バンドルID」（＝アプリの世界で1つだけの名前。例：`com.yourname.sasattakashi`）を聞かれたら、自分の名前などを入れて決めます。

### B. 今後の拡張アイデア

| アイデア | 難しさ | メモ |
|---|---|---|
| 歌詞の編集機能 | やさしい | 一覧のカードをタップ → 編集画面 |
| 共有シートから直接保存 | ふつう〜難しい | `expo-share-intent` などのライブラリ ＋ EAS Build が必要（Expo Go では不可） |
| Spotify の再生中の曲名を自動入力 | ふつう | Spotify Web API（ログイン連携）。歌詞は取得できないので曲名・アーティスト名のみ |
| ホーム画面／ロック画面ウィジェット | 難しい | `expo-widgets` / `@bacons/apple-targets` などで実現できる可能性あり（EAS Build が必要） |
| 他の人にも公開 | ふつう | App Store 審査。歌詞はユーザー自身が保存する個人利用の形を保つ |

一つずつ、小さく動かしながら進めていきましょう。
