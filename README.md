# 刺さった歌詞

歌を聴いたり歌ったりしていて心に刺さった歌詞を保存しておき、ふとした瞬間にまた見返せる iPhone アプリです。
Expo（React Native）で作っているので、Mac がなくても Windows で開発できます。

## できること（MVP）

1. **保存**：歌詞の一節・曲名・アーティスト名（＋任意のメモ）を保存
2. **一覧**：保存した歌詞をカードで見返す（ランダムに1つ選ぶ／長押しで削除）
3. **ランダム通知**：毎日決まった時刻に、保存した歌詞からランダムに1つを通知

保存したデータは iPhone の中だけに保存され、外部には送信されません。

## はじめかた

👉 **[Windowsで動かす手順（初心者向け）](docs/setup-windows.md)**

```powershell
cd lyrics-app
npm install
npx expo start
```

表示された QR コードを iPhone のカメラで読み取り、Expo Go で開きます。
